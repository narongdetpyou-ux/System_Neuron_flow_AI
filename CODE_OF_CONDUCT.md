# Code of conduct

> ภาษาไทย: ทุกคนที่มาร่วมในโปรเจกต์นี้ต้องให้เกียรติกัน ไม่คุกคาม ไม่ดูหมิ่น และไม่เปิดเผยข้อมูลส่วนตัวของผู้อื่น
> ถ้าพบพฤติกรรมไม่เหมาะสม แจ้งแบบส่วนตัวผ่านแท็บ Security → Report a vulnerability แล้วเขียนว่าเป็นเรื่องความประพฤติ

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in every project space: issues, pull requests, discussions and reviews.

## In short

- Be respectful and welcoming, and accept that people disagree.
- Give and take criticism about the work, never about the person.
- No harassment, insults, sexualised language or imagery, or personal attacks.
- Never publish anyone's private information, such as an address or an e-mail address, without their
  explicit permission. This project already keeps all personal data out of the repository.

## Reporting

This repository publishes no e-mail address. To report behaviour privately to the owner, open the
repository's **Security** tab, choose **Report a vulnerability**, and say in the title that it is a conduct
report; only the owner can read it. You can also use GitHub's **Report content** on a comment, which goes to
GitHub. Reports are kept confidential.

## Enforcement

The owner reviews every report and may edit or remove contributions, lock a conversation, or block an
account, following the Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban).
